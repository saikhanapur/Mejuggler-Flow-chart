<analysis>**original_problem_statement:**
The user's primary goal is to create a world-class application that transforms complex Standard Operating Procedure (SOP) documents into accurate, interactive, AI-generated flowcharts. The project has pivoted from a simple design to a new, innovative vision focused on creating a new market category of AI Process Visualization. The core mission is to Make process documentation 100x faster. The user has specified that they often upload visual PDFs (flowcharts) and not just text-based documents, and the system must handle this input type correctly, extracting all information including text from annotations (e.g., yellow boxes). A critical feature is the correct rendering of decision points as diamond shapes and displaying all Actionable Intelligence (contacts, templates, scripts) in a well-organized manner.

**PRODUCT REQUIREMENTS:**
1.  **Actionable Intelligence (Core IP):** The application must perform a deep analysis of the source document, extracting not only the process steps but all supporting non-flowchart information (contacts, email templates, system links, troubleshooting guides, communication scripts). This data must be intelligently structured and linked to the relevant nodes in the flowchart.
2.  **Complex Document Processing:** The system must reliably process large, real-world SOPs, including visual PDFs, without timing out, losing data, or producing inaccurate results.
3.  **Innovative & Intuitive UI:** The UI must be clean, professional, and mobile-friendly. Key features include animated live connections, smart expandable nodes, and clear, user-approved color schemes.
4.  **Accuracy:** The AI must correctly identify all swim lanes, loops, parallel processes, and especially decision points, which must be rendered as diamond shapes with clear, correctly placed YES and NO branches.

**User's preferred language**: English

**what currently exists?**
The application is a full-stack solution (React/FastAPI/MongoDB) that has recently undergone significant changes. A new hybrid vision processing pipeline has been implemented using the native Anthropic (Claude) SDK to handle visual PDFs, a key user requirement. 1.  **Extraction Review:** After a document is uploaded, a modal appears showing the user all the Actionable Intelligence (contacts, critical actions, scripts) that the AI has extracted.
